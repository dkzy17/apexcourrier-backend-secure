### ApexCourrier Frontend

This is the frontend application for ApexCourrier, a comprehensive delivery and logistics management platform.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the ApexCourrier customer-facing website.

## Features

- **Customer Portal**: Browse services, track packages, and manage deliveries
- **Real-time Tracking**: Track packages in real-time with live updates
- **Service Information**: Comprehensive information about delivery services
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices

## Tech Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **Icons**: React Icons

The application is configured for deployment to Vercel or any other Next.js-compatible hosting platform.
