# ApexCourrier Admin Dashboard

This is the admin dashboard for ApexCourrier, a comprehensive delivery and logistics management platform.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to access the ApexCourrier admin dashboard.

## Features

- **Package Management**: Create, update, and track packages
- **Real-time Tracking**: Monitor package status and location in real-time
- **User Management**: Manage customer accounts and permissions
- **Invoice Generation**: Create and print professional invoices and receipts
- **Analytics Dashboard**: View delivery statistics and performance metrics

## Tech Stack

- **Framework**: Next.js 15
- **Styling**: Tailwind CSS 4
- **Animation**: Framer Motion
- **Icons**: React Icons

## API Integration

The admin dashboard connects to the ApexCourrier backend API at `https://veno-atlas-2.onrender.com/api`.
